# 사이트 폴더로 Codex 프로젝트 만들기

개설자·합류자 모두 첫 단계에서 쓴다. 목표: `sites` 폴더 안에 사이트 이름의 **빈 폴더**를 만들고, 그 폴더로 Codex(또는 Claude) 프로젝트를 연다.

위치:
- **Windows**: `C:\Users\<사용자>\sites\<사이트이름>` (`%USERPROFILE%\sites\<사이트이름>`)
- **Mac**: `~/sites/<사이트이름>`

Windows에서 **문서·바탕 화면은 쓰지 않는다.** 이유: 많은 PC에서 두 폴더가 OneDrive로 옮겨져 있어 위치가 헷갈리고, 사이트의 설치 파일(`node_modules`, 수만 개)이 클라우드로 동기화되면서 느려지거나 파일이 잠긴다.

사이트 이름은 영어 소문자·숫자·`-`만 쓴다(예: `my-portfolio`). 레포 이름이 된다.

## 안내 문구 (사용자에게 그대로)

**Windows**
> 1. Codex 왼쪽 **프로젝트** 옆 **+** → **로컬 폴더 선택**을 누르면 폴더 고르는 창이 떠요.
> 2. 창 **맨 위 주소창**을 클릭하고 `%USERPROFILE%` 를 입력한 뒤 **Enter**. 내 사용자 폴더로 이동해요.
> 3. 창 위쪽 **새 폴더** → 이름 `sites` → 더블클릭해서 들어가기. (이미 있으면 들어가기만)
> 4. 다시 **새 폴더** → 사이트 이름(예: `my-portfolio`) → 그 폴더를 한 번 클릭하고 **폴더 선택**.
> 5. 왼쪽에 생긴 그 프로젝트에서 **새 채팅**.

**Mac**
> 1. Codex 왼쪽 **프로젝트** 옆 **+** → **로컬 폴더 선택**을 누르면 폴더 고르는 창이 떠요.
> 2. **Command + Shift + H**를 누르면 내 홈 폴더로 이동해요.
> 3. 아래쪽 **새로운 폴더** → 이름 `sites` → 들어가기. (이미 있으면 들어가기만)
> 4. 다시 **새로운 폴더** → 사이트 이름 → 그 폴더를 고르고 **열기**.
> 5. 왼쪽에 생긴 그 프로젝트에서 **새 채팅**.

**Claude 앱**: 새 대화를 시작할 때 작업 폴더를 고르는 곳에서 같은 방법으로 폴더를 고른다.

창 모양이 설명과 다르면 스크린샷을 받아 그 화면 기준으로 다시 안내한다.

## 이미 문서·OneDrive 아래에 만들었다면

그대로 진행해도 동작은 한다. 다만 느리거나 "파일이 사용 중" 오류가 나면 위 위치로 새로 만드는 게 낫다고 알린다. 사이트 레포를 받기 전이면 지금 옮기는 게 가장 쉽다.
